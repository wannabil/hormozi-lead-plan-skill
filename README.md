# hormozi-lead-plan (AI agent skill)

Playbook lead generation Alex Hormozi ($100M Leads) dalam format `SKILL.md`, supaya AI agent korang boleh terus buat lead plan untuk bisnes korang.

Alex Hormozi's $100M Leads playbook as an agent skill (Bahasa Melayu): lead magnet, the Core Four, Rule of 100 and a 30-day plan.

## Cara guna

1. Download folder [`hormozi-lead-plan/`](hormozi-lead-plan/SKILL.md).
2. Letak dalam folder skills agent korang:
   - Claude Code: `~/.claude/skills/hormozi-lead-plan/SKILL.md`
   - Hermes Agent: `~/.hermes/skills/hormozi-lead-plan/SKILL.md`
   - Claude.ai: zip folder tu, upload dalam bahagian Skills kat Settings.
3. Tanya agent: "Buat lead plan 30 hari untuk bisnes aku (jual apa, siapa customer, bajet berapa)."

Tak guna agent? Copy je isi `SKILL.md` dan paste dalam chat Claude / ChatGPT sebelum tanya.

## Apa dalam skill ni

- Formula: lead magnet → Core Four tiap hari → orang lain tolak
- Core Four: warm outreach, free content, cold outreach, paid ads
- Rule of 100 selama 100 hari
- Plan 30 hari + cara track nombor
